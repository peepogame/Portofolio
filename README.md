# Arsha M. Rayhan — Executive Portfolio

Portofolio web interaktif berbasis strategi bisnis, pemodelan finansial terstruktur, optimalisasi rantai pasok (supply chain), dan pengawasan operasional (QC).

---

## 🚀 Cara Membuka / Menjalankan

Portofolio ini dibangun dengan arsitektur **zero-dependency** (HTML5 + Tailwind CSS + Chart.js + Lucide Icons). Tidak memerlukan Node.js, npm, atau server instalasi khusus.

### Opsi 1: Buka Langsung di Browser
Cukup **klik dua kali** (double-click) file [`index.html`](./index.html), atau klik kanan lalu pilih **Open with Google Chrome / Microsoft Edge / Firefox**.

### Opsi 2: Buka via PowerShell / Terminal
```powershell
Start-Process "index.html"
```

### Opsi 3: Deploy ke GitHub Pages / Vercel
File `index.html` dapat langsung diunggah ke repository GitHub dan diaktifkan melalui **GitHub Pages** (Settings > Pages > Branch main / root) untuk mendapatkan URL online publik gratis (misal: `https://arsharayhan.github.io`).

## 📌 Ringkasan Konten Portofolio

### 1. Header & Executive Summary
- **Profil & Spesialisasi**: Strategi Bisnis, Pemodelan Finansial, Optimalisasi Rantai Pasok, Pengawasan Operasional.
- **Tautan Kontak Cepat**: Email langsung, profil LinkedIn, dan tautan platform Avyra.
- **Export to PDF**: Tombol siap cetak / simpan ke format PDF untuk lampiran lamaran kerja.

### 2. Studi Kasus 1: AVYRA (Strategy, Financial Modeling & Product Logic)
- **Dinamika Pasar**: Data penurunan lowongan entry-level sebesar 29% dan 68% lowongan mensyaratkan pengalaman kerja.
- **Top-Down Market Sizing**: Visualisasi interaktif TAM (250k), SAM (50k), dan SOM (2.5k) mahasiswa.
- **Unit Economics & BEP Interaktif**:
  - Tabel margin unit: Validasi Expert (33.3%), Marketplace Take-Rate (94.6%), B2B SaaS (94.0%).
  - **Simulator & Grafik BEP Dinamis**: Slider interaktif jumlah akun langganan B2B (Rp250.000/bln) terhadap biaya operasional tetap (Rp15.000.000/bln), dengan titik impas tepat pada 60 akun.
- **Arsitektur Sistem (Product Logic)**: Diagram alur transaksi dan escrow nilai antara Mahasiswa, UMKM, dan Pakar Industri.
- **Bukti Eksekusi**: Pratinjau antarmuka web langsung dan dokumentasi pameran stan/expo bisnis.

### 3. Studi Kasus 2: Patché (Operations, Supply Chain & Quality Control)
- **Peta Rantai Pasok (Supply Chain Flow)**: Diagram 3 tahap dari pengadaan limbah celana jeans bekas (upstream), perakitan penjahit UMKM lokal (midstream), hingga dual distribusi online & pop-up offline (downstream).
- **Value Proposition Canvas & SDGs**: Matriks VPC (Customer Profile vs Value Map) dan penyelarasan dengan SDG 8 (Decent Work), SDG 12 (Responsible Consumption), dan SDG 13 (Climate Action).
- **Evaluasi Mutu & Mitigasi Operasional (QC Lessons Learned)**: Tabel audit prototipe tas laptop 14 inci & 15 inci (kerapian jahitan ganda nilon, pelindung ritsleting, dan stabilitas pasokan bahan).

### 4. Studi Kasus 3: Simulasi Bisnis Harvard (Data-Driven Decision Making)
- **Coffee Shop Inc.**: Penetapan harga dinamis (price elasticity), alokasi biaya pemasaran berbasis ROI, dan optimasi jadwal shift kerja barista untuk memaksimalkan margin EBITDA.
- **Net Zero Policy**: Analisis efisiensi energi operasional pabrik, perhitungan CapEx vs periode payback investasi energi terbarukan, serta mitigasi risiko neraca keuangan korporasi.
